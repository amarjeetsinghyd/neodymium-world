Scaling Autonomous Coding Agents Across 15,000 Repositories

Amarjeet Singh Senior Analyst
Tue, 24 No 7 Min Read

Strategic Intelligence Desk: Curated and verified by Senior Analyst Amarjeet Singh. Directed toward defense sovereignty, Indo-Pacific deterrence, and critical emerging technologies.

Key Takeaways

  • • The Remote Agents Platform standardizes agentic tasks across 15,000 repositories using an internal REST API interface.
  • • Combining deterministic bookends (cloning, publishing) with stochastic agentic execution guarantees workflow predictability.
  • • Operating at scale yielded over 25,000 runs with an average inference cost of just US$0.04 per task.
  • • The integration of OpenAI’s Structured Outputs ensures automated, contract-compliant verification of agent success or failure.

The Architectural Bottleneck of Enterprise Scale

Managing software lifecycles across massive enterprise ecosystems historically collided with a fundamental infrastructural ceiling. While individual engineering teams easily conceived automation use cases for single codebases, multiplying those routines across thousands of repositories introduced severe fragmentation. The core engineering bottleneck was never a lack of intelligence or capability within large language models; it was the absolute absence of a dedicated, scalable execution runtime. Without a centralized agentic layer, technical units repeatedly built redundant, brittle point solutions that failed to scale under production pressures.

To eliminate this systemic friction, iFood’s engineering organization designed the Remote Agents Platform, transforming complex software maintenance into straightforward API invocations. Rather than forcing product teams to master agent orchestration, the platform provides a unified REST interface that handles lifecycle management entirely behind the scenes. Developers simply submit prompts and environment parameters, while the platform provisions isolated infrastructure to execute the workload asynchronously. This architectural shift redefines how large engineering organizations approach routine maintenance, dependency patching, and large-scale code validation.

Engineering Predictability Through Sandboxed Execution

Operating autonomous agents across sensitive enterprise perimeters demands absolute containment and predictable execution pathways. The Remote Agents Platform achieves this by enforcing a strict architectural separation between deterministic scaffolding and stochastic model reasoning. Every workflow begins and ends with deterministic steps: cloning the repository, importing required agent capabilities, setting up working branches, publishing merge results, and archiving artifacts. These bookends require zero probabilistic intelligence, ensuring that environment setup and final integration operate with mechanical reliability.

"Solving this for one repository is easy. The challenge is solving it at scale across all 15,000 repositories."

Sandwiched securely between these deterministic anchors lies the agentic execution phase, operating inside isolated Ubuntu environments tailored to the organization's diverse technology stack. The runtime natively integrates essential toolchains spanning Python, Java, Kotlin, C#, TypeScript, Rust, and Go, alongside direct access to internal enterprise utilities like GitLab, Nexus, Docker, Snyk, Kubernetes, and AWS. By routing execution through this controlled sandbox, the platform guarantees that autonomous agents operate with the precise permissions and dependencies required to execute complex refactoring safely.

Balancing Intelligence, Speed, and Economic Viability

At a scale exceeding 25,000 completed runs and billions of tokens consumed, model selection transitions from a theoretical benchmark exercise into a strict economic constraint. The engineering team selected GPT-5.6 Luna after evaluating models on a strict triad of requirements: high reasoning intelligence, operational efficiency, and rapid execution speed. For an internal platform handling enterprise-wide workloads, maintaining an average inference cost of just US$0.04 per run is an essential architectural achievement that dictates long-term financial sustainability.

Furthermore, verifying the success of autonomous actions at scale presents an inherent operational hurdle. iFood resolved this by enforcing strict post-execution validation using OpenAI’s Structured Outputs, which mandates that every agent response conforms to a predefined programmatic contract. This verification layer automatically classifies operational outcomes as positive or negative without requiring human intervention, enabling the system to scale its throughput securely across thousands of concurrent repositories without sacrificing code integrity.

Unlocking Asynchronous Productivity Across the Enterprise

The true return on investment delivered by the Remote Agents Platform lies not merely in execution speed, but in the liberation of human engineering capital. Because tasks execute asynchronously within isolated sandboxes, developers are entirely freed from the cognitive burden of monitoring routine execution loops. Engineers routinely launch complex security fixes, performance profiling, and dependency upgrades while stepping into architectural reviews, delegating mechanical toil entirely to the platform.

This capability was decisively proven during the rollout of an internal security product designed to scan and remediate vulnerable dependencies across all 15,000 repositories. Following migration to the Remote Agents Platform, the accuracy of these automated security fixes more than doubled, while the absolute volume of resolved vulnerabilities surged. By treating agentic execution as foundational infrastructure rather than a novelty, the organization has established a repeatable blueprint for engineering productivity in the era of autonomous systems.
